About Me

My research focuses on lightweight authentication and security for automotive CAN networks, embedded and real-time systems, and machine-learning-based attack analysis. I am particularly interested in practical security mechanisms that can be implemented and evaluated on resource-constrained automotive platforms.

Featured Research

Lightweight PUF-Based CAN Authentication

Authentication framework for securing ECU communication in automotive CAN networks using Physical Unclonable Functions.

  • LFSR-based response obfuscation
  • ECC-assisted error correction
  • Protection against replay, impersonation, and modeling attacks
  • FPGA and Arduino-based CAN implementation
  • Real-time latency and overhead evaluation
